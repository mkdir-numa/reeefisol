# Logo sources

**No written permission to use any of these logos has been obtained yet. Get written OK from each organization before publishing.**

All files were downloaded on 2026-10-13 from the organization's own website, its brand/press kit page, or its official GitHub org. Each SVG was checked: no `<script>`, no event handlers, no external references. "Light bg" means the file reads on a white/light background; "dark bg only" means it has white or cream text and needs a dark background.

None of the older files in `assets/` (partner-*.png) were reused. They match the current official logos, but they are cropped screenshots with a dark background baked in. Official SVG or larger transparent PNG versions were found for all of them and used here instead.

## Caveats

- No dark-text (light-background) version could be found for: Pine Stake (white SVG only), Phase (cream; its brand kit says not to place logos on light backgrounds), Vault wordmark, Dyno, BlazeStake wordmark, Stakewiz wordmark and validators.app. For light sections, use the square marks where available (vault-mark.png, definity.png, blazestake-mark.png, stakewiz-mark.png) or put the logo on a dark tile. Solana Foundation and Solscan guidelines forbid recoloring.
- definity.finance, dynosol.io, jagpool.xyz, thevault.finance and phase.cc/delegation are also linked as these programs' sites from validators.app, which supports these being the right domains.
